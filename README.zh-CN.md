# Drawio Preview

[English](README.md) | [简体中文](README.zh-CN.md)

Drawio Preview 在 Obsidian 里渲染 `.drawio` 图表 —— 笔记中的嵌入和 `.drawio` 文件视图都支持，但**不提供内嵌编辑器**。图表由内置的 drawio 查看器绘制成 SVG；在桌面端点击预览，会打开可缩放、可拖动、可全屏的交互式查看器，也可以把文件交给本地的 drawio 软件去编辑。

![Drawio Preview 效果](https://github.com/user-attachments/assets/c70cce74-0450-41e3-a9e8-8aeb98738f99)

## 功能特性

- **只读预览。** `![[图表.drawio]]` 和 `.drawio` 文件即刻出图。编辑仍然在桌面版 drawio 里进行 —— 查看器的**编辑**按钮会用系统默认应用打开该文件。
- **预览缓存。** 一张图第一次渲染要等一会儿，之后直接命中缓存，不再加载 drawio 内核。
- **链接控制尺寸。** 沿用 Obsidian 原生的链接写法：`![[图表.drawio]]` 自适应栏宽，`![[图表.drawio|400]]` 指定宽度，`![[图表.drawio|400x300]]` 指定宽高。图表在框内等比缩放。
- **多页图表。** 多页文件会出现 `‹` / `›` 翻页按钮；固定按钮会把当前页写进链接，下次打开仍停在这一页。
- **交互式查看器（桌面端）。** 放大、缩小、适应、拖动已放大的图表、全屏。按 `Esc` 退出全屏。
- **三种外观。** 浅色、深色、透明，也可以跟随 Obsidian 当前主题。
- **新建图表。** 命令、功能区按钮和文件夹右键菜单都能创建一个空的 `.drawio` 文件 —— 放在附件目录、当前笔记所在文件夹，或你在设置里指定的文件夹。

## 安装

### 从社区插件市场安装

1. 打开 Obsidian 的 **设置 → 第三方插件**，确认已关闭「安全模式」。
2. 点击 **浏览**，搜索 **Drawio Preview** 并安装。
3. 启用插件。

### 手动安装

1. 从[最新版本](https://github.com/nnq7/obsidian-drawio-preview/releases/latest)下载 `main.js`、`manifest.json` 和 `styles.css`。
2. 在 `<你的仓库>/.obsidian/plugins/drawio-preview/` 下建好目录，把这三个文件放进去。
3. 重开 Obsidian，在 **设置 → 第三方插件** 里启用 **Drawio Preview**。

## 使用方法

### 嵌入图表

```markdown
![[图表.drawio]]
![[图表.drawio|400]]
![[图表.drawio|400x300]]
![[图表.drawio#p1]]
```

尺寸语法和 Obsidian 插入图片时完全一致，所以不用重新记一套规则。直接改链接里的数字，预览会立刻跟着变。

### 操作预览

点击预览即可激活，右上角出现工具栏：

| 按钮        | 作用              |
| --------- | --------------- |
| `+` / `−` | 放大 / 缩小（桌面端）    |
| 适应        | 回到适配框的大小        |
| 编辑        | 用默认应用打开该文件（桌面端） |
| 全屏        | 把预览放大到整个屏幕（桌面端） |
| `×`       | 退出全屏            |

放大之后可以按住拖动来平移。点击预览以外的区域会取消激活。

### 多页图表

用 `‹` 和 `›` 翻页。点击固定按钮会把当前页以 `#pN` 锚点的形式写进嵌入链接（第一页是 `#p1`，第二页是 `#p2`，依此类推），重开笔记仍显示那一页。

### 新建图表

可以用命令 **Drawio Preview: 新建图表**、功能区图标，或文件夹右键菜单里的 **新建 drawio 图表**。文件落在哪里由设置里的**新建图表位置**决定。

## 配置说明

| 设置项          | 说明                                                          | 默认值          |
| ------------ | ----------------------------------------------------------- | ------------ |
| **新建图表位置**   | 命令新建的图表保存位置：跟随 Obsidian 的附件目录、与当前笔记相同的文件夹，或下方指定的文件夹。        | 跟随附件位置       |
| **下方指定文件夹**  | 只有位置选了「下方指定文件夹」时才可编辑。输入时支持文件夹模糊匹配，目录不存在会自动创建。               | —            |
| **图表预览外观主题** | 开启「跟随主题」时预览跟随 Obsidian 的浅色 / 深色主题，下拉框不可用；关闭时由下拉框决定浅色、深色或透明。 | 跟随主题，浅色      |
| **缓存文件个数上限** | 最多保留多少个预览缓存文件，超出后按写入时间删除最旧的。只删缓存文件，不会动你的图表。                 | 20（范围 10–30） |

## 数据、隐私与权限

这个插件按「完全离线可用」设计：

- **不发起任何网络请求。** drawio 查看器已经打包进 `main.js`，运行时不下载任何东西。
- **没有遥测，也没有统计。** 插件不收集、不上传、不保存任何使用数据。
- **对仓库的访问是只读的**，只有两处例外：
  - **编辑**按钮会请操作系统用默认应用打开**这一个** `.drawio` 文件。
  - 预览缓存写在 `<你的仓库>/.obsidian/plugins/drawio-preview/cache/`。里面只有渲染出来的 SVG，数量受上面的设置限制，随时可以整目录删除 —— 插件会按需重新生成。
- **不访问仓库之外的文件。**
- 移动端显示的是静态预览，无法交互。

## 常见问题

**为什么第一次打开会卡顿？**  
第一次显示某张图时，插件要加载内置的 drawio 查看器（约 2.7 MB）并完成渲染。结果会被缓存，之后同一页几乎立刻出图。换一页或文件有改动，才会需要重新渲染一次。

**点了「编辑」没反应。**  
它是把文件交给操作系统的，所以 `.drawio` 需要有默认关联程序。装好 drawio 桌面版（或把该文件类型指向网页版）之后再试。

**缓存在哪？能清掉吗？**  
在 `<你的仓库>/.obsidian/plugins/drawio-preview/cache/`。随时可以删掉整个目录，插件会按需重建。保留多少个文件由**缓存文件个数上限**控制。
